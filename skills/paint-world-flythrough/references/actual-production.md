# 实际制作与验收

## 能力与路线

先检查可调用的模型、渲染器和依赖。技能文本不等于模型权限。对真实绕行要求先解决几何或视频模型，不用静图推拉作为最终替代。

便携Blender脚本适用于有APT索引的Debian/Ubuntu x86_64；没有索引时先正常更新索引，或使用平台现有安装方式。依赖下载不能绕过环境明确拒绝的权限或网络政策。macOS/Windows使用各自已授权的安装方式。运行 `blender --version` 不能代替一帧渲染测试。

便携安装没有加入PATH时，把包装器路径传给 `check_capabilities.py --blender-wrapper PATH`，或使用 `PAINT_WORLD_BLENDER`。调用安装生成的包装器，不直接调用解包的二进制；部分工作区快照会截短大型二进制，包装器会从完整deb重新解包。不存在PATH命令不等于未安装；仍需通过包装器实际渲染验证。

## 河岸场景蓝图

`build_river_scene.py` 生成完整船体、船内甲板、桅杆与缆索、远岸实体建筑、河岸、三维水面笔触、人物体块及世界固定的绘画天空背景。场景以连续相机路径穿行并绕船，最后升高退远。原画未展示的侧面、河岸地理和人物体块均属创作补全。

先通过imagegen生成四格无文字油画材质：左上深蓝水面；右上深蓝绿木料；左下赭黄橄榄色地面；右下蓝灰墙面。源画为风格和色板参照。脚本通过UV读取四格，图像打包到blend，不要求额外保留绝对素材路径。

```bash
blender -b -t 4 --python scripts/build_river_scene.py -- \
  --source painting.png --atlas paint_atlas.png --output river_world.blend \
  --preview-dir qa --width 960
```

先检查预览中的场景身份、船体侧面、桅杆遮挡、天空是否固定在世界与油画纹理尺度。蓝图是起点，不保证复现任何指定画作；根据画面修正。不要宣称单图精确恢复了真实地形。

## 渲染

根据首帧实测选择引擎、样本数和原生尺寸。EEVEE无法初始化时检查合法可用的EGL/软件渲染，或使用Cycles CPU。按绝对路径输出图像序列或视频。可以保留静态几何与材质，只动画相机和轻微水面；减少无必要的物体动画。

渲染结束核验帧数、时长、分辨率、帧率，并完整解码。抽看近镜、侧面、出遮挡、全景、结尾与接点。原画结尾用后期明确切回并停留1–3秒。不得称这一步为精准三维变形。

## 必须通过的穿行检查

- 相机位移在三维世界发生，不只是静图裁切。
- 同一船或建筑在三个视角有一致的新侧面。
- 近物在镜头前遮挡，解除遮挡后远景维持布局。
- 相机不穿入实体；水面、岸边有正确远近关系。
- 油画材质贴在表面，近镜不突然成为普通灰模或写实摄影。
- 明确记录建模补全、插帧和放大，不能掩盖制作边界。
