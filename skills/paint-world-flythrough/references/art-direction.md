# 全场景油画美术

## 制作顺序

1. 用干净原画建立色板、笔触尺度、近中远层次及主体轮廓；参考片用于确认体验机制，不能把不同画作的色彩与地理硬套过来。
2. 先决定全片镜头经过的实体。补齐近景、侧面、背面和承托面；树、人物和木桩必须落在岸坡、地面或其他合理实体上。
3. 按用途生成素材：完整天空；建筑立面语义贴图（门窗、百叶、门）；屋顶/石岸/地面/树皮；船板；透明枝叶。纹理提示应约束到“平面正交表面、无透视、无背景、无文字”，避免把透视场景直接贴上模型。
4. 分开分配表面与UV。屋顶、墙面、船板和地面不能共用大幅重复图造成拉丝；建筑立面各面按完整门窗绘画映射，长曲面用连续UV，地面按世界尺度铺设。四格图先按格处理，不能越格读到其他材质。
5. 同时设计色块与轮廓。手绘深色轮廓、磨损边沿、明暗与笔触都要落实；增加分辨率不能替代这些步骤。
6. 用真实曲线分叉和空间分布的透明枝叶簇制作树冠。枝叶簇可为平面叶片，但整体必须有体积与视差，不能用整幅原图缩放冒充三维。
7. 渲染入口、主体侧面、主体背侧、前景遮挡、遮挡解除、全景。近镜检查纹理尺度与细节；全景检查源画地标比例、布局和明暗。
8. 完成内部5秒最难镜头后，按用户请求渲染完整影片。不是用户明确要样片时，不以试制片结束任务。

## 画面验收

| 项目 | 实际检查 | 失败处理 |
| --- | --- | --- |
| 空间 | 同一地标的新侧面、遮挡解除后仍在、根部有实体支撑 | 重建缺失几何 |
| 材质 | 近镜仍是笔触，立面有门窗与轮廓，UV无拉丝或错格 | 重新画图或调整UV |
| 水面 | 河面与倒影均可见，运动相位一致，无闪烁与大片空底 | 检查Shader与坐标，不以解码通过代替画面通过 |
| 树木 | 透明边缘正常、空间有层次、相机不穿入树干 | 调整枝叶分布、机位和承托面 |
| 运镜 | 接近、侧绕、升高、离开、减速连贯，无无故倒向 | 改相机曲线并清空旧缓存 |
| 收尾 | 完整原图、简介不盖主体、阅读时间足够 | 重新排版与核实事实 |

按可见证据描述完成程度。“全部地标已细化”与“和参考美术完全相同”是不同的判断；帧数、像素尺寸与成功导出不能证明后者。
