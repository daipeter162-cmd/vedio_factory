# 名画沉浸式穿行

先设计空间和镜头，再调用制作工具。默认叙事机制：先体验画中世界，最后认出原画。用户要视频时，默认目标是实际出片。

## 输入与默认值

- 使用用户提供的作品图、参考视频、目标比例、时长和可用工具。缺项先从当前对话推导，不重复索要已知素材。
- 默认中文、16:9、约20秒、30fps、无口播。竖屏需求必须重新构图，不能直接裁掉关键地标。
- 只有视频时先做解析；制作需使用干净原画或用户自有素材，不把他人带水印截图当新视频交付素材。
- 把原图作为最终构图目标；把新增街道、建筑背面、桥梁和树枝标成空间补全，避免当画作史实。
- 不替用户购买服务。缺少调用能力或授权时交付制作包，明确尚未生成的素材。

## 1. 建立参考证据

有参考视频时运行 `scripts/prepare_video_evidence.py`，读取元数据并按源时间抽帧；在变换、遮挡和结尾处加密。不要把fps滤镜输出序号直接当精确源时间。

记录起始空间、地标、相机移动、遮挡、纹理变化、原画出现时间、平台附加尾页。音频没有听验或可靠转写时写“音轨未鉴定”，不编造配音、歌名或语音模型。

区分三个标签：**观察**为带时间点的可见事实；**推断**为有依据且有替代解释的制作判断；**复现设计**为自己新写的流程和提示词。仅有成片时不得声称恢复原prompt、seed、软件、版本、生成次数或成本。

需要《星月夜》案例时读取 `references/source-analysis.md`；不能把案例时间线硬套到其他作品。

## 2. 检查能力并选择主路线

先运行 `scripts/check_capabilities.py`。技能提供流程和脚本，不能凭安装技能获得视频模型权限。需要外部模型时先搜索可用插件，只有确认连接后才调用；不得把推荐或安装卡当成已连接。用户允许安装工具时，主动安装可逆依赖。Linux缺少Blender时可运行 `scripts/install_blender.sh OUTPUT_DIRECTORY` 建立隔离的便携运行环境；然后实际渲染一帧确认可用。

| 目标与条件 | 路线 | 交付边界 |
| --- | --- | --- |
| 稳定绕建筑、露出背面、重复修改运镜 | 三维场景 | 布局、建模/贴图简报、相机路径；有三维工具时再实现 |
| 快速样片，接受少量几何变化，有图生视频工具 | AI关键帧 | 关键帧、短段提示、接续与重试；不承诺完全一致 |
| 只有静图和图层动画工具 | 2.5D预演 | 分层推拉视差；明确不能真实露出建筑新侧面 |

按用户目标选择，不因用户提到AI就断言参考由AI生成。

用户要求参考中的穿行、绕行或新视角时，默认选择三维或AI路线。没有模型接口时，优先尝试本地三维工具。不得自动降级到2.5D后称达到参考效果。2.5D仅限用户明确接受预演，或作为内部构图检查；核心能力确实无法接通时交付具体制作包，说明缺口。

三维实现读取 `references/actual-production.md`。夜景河岸、船与城市可用 `scripts/build_river_scene.py` 作为起点，传入原画、生成的四格油画材质和输出路径。该脚本是明确建模的河岸蓝图，不是通用单图三维恢复器；其他画作必须调整地标、几何、材质、相机，不能硬套河岸。

## 3. 固定空间约束

给地标分配ID，例如L1教堂、L2前景树、L3远山、L4天空旋涡。记录相对位置、尺度、颜色、轮廓、可见面、相机接近/离开时间与新增空间。分清平面构图关系和重建的三维地理关系。

全片固定色板、笔触尺度、光源方向、夜晚亮度和建筑身份。风格落实到建筑、道路、树木与天空的表面，不能只写“某画家风格”。

## 4. 倒推终点与关键帧

先锁定原画收尾，再设计接近它的全景，最后补中景、近景和入口帧。起点与终点差异太大时增设过渡帧，不要求模型在几秒内跨越整个世界。

默认四个约4-5秒的制作单元：

1. 沿道路低位进入，以前移为主，保持地标方向。
2. 接近地标并平滑升高/小幅侧绕，保持同一建筑。
3. 向外退开，让树干或屋檐形成可选的遮挡接点。
4. 拉远并减速，稳定构图，再叠化或明确切到干净原画，停留1-3秒。

四段是复现制作单元，不能反向声称参考作者按四段生成。

## 5. 写提示词或三维简报

读取 `references/camera-prompts.md`。按“参考图/场景身份 + 表面材质 + 单一主运镜 + 尾帧状态 + 连续性约束”填入当前作品与地标。

- AI路线先确认关键帧，再写逐段提示；首尾帧、负面提示、seed只在工具支持时使用。相同seed不等于几何一致。调用前核验当前官方接口，不编造参数。
- 不支持尾帧时使用上一段末帧作为下一段首帧，或用工具提供的延长功能；定期用已确认地标校正累计漂移。
- 三维路线明确布局、几何、材质、光照、相机路径和最终匹配相机。可以一条相机曲线连续渲染，不必真的拆四次。
- 2.5D仅设计图层平移、缩放和遮挡，不要求看见新侧面。
- 不在生图时生成中文介绍、平台水印或二维码；后期添加自有字幕。

## 6. 接续与验收

检查接点前后至少各0.5秒的运动方向、轮廓与曝光。遮挡能隐藏拼接，但不能修复错误地理关系。结构严重变形时重做该段，不用长叠化掩盖。

- 尖顶、屋顶边线、树干方向稳定，不复制或突然消失。
- 近景移动快、远景移动慢，形成合理视差。
- 近镜仍保留笔触，局部不变写实照片。
- 运镜进入、升高/离开、最后减速，不无故倒向。
- 最后地标关系接近原画；有切换时如实描述，不宣称无缝变形。
- 不把源视频中的平台附加尾页加入新成片。
- 艺术穿行默认音乐方案；科技教程另加口播，不强行沿用该案例节奏。

AI试制先验证最难的约5秒，如绕教堂保持尖顶；通过后再扩展。先小规模实测再估算时间与花费，不承诺一次成功。

三维试制至少渲染入口、主体侧面、离开后的三个视角。确认侧面确为几何，近物能遮住远物、遮挡解除后场景仍在，镜头没有穿船或穿墙。仅观察到静图边缘平移和缩放不能通过穿行验收。正式交付注明原生渲染尺寸与帧率；插值或放大不能标成原生质量。对结尾使用明确切回原画时如实说明。

## 必须交付

1. 制作机制、主路线与未确认项。
2. 空间约束表与按秒的分镜表，含首帧、主动作、尾帧、风险、接点。
3. 全局提示、关键帧提示、逐段运镜提示；三维路线提供可实施简报。
4. 已完成/待执行清单和验收结果。生成了方案不能称已出片；实际生成视频才称已制作。

保存可读制作包，保持源素材只读，遵循当前环境的持久化与技能依赖规则。
