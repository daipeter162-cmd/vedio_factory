# 名画沉浸式穿行工作流

目标是交付完整视频：有真实空间与新侧面的连续运镜，全场景绘画美术，以及完整原图和核实后的作者简介。

## 固定流程

| 阶段 | 输入与行动 | 通过条件 |
| --- | --- | --- |
| 1. 参考取证 | 对原视频按源时间抽帧，拆解前景、地标、侧绕、遮挡与原画出现 | 区分观察、推断、自己的复现设计 |
| 2. 选制作路线 | 检查本地工具；选Blender或Three.js真实三维，后期选Remotion | 实际出一帧，不能把安装技能当获得模型权限 |
| 3. 空间规划 | 倒推最终全景，再设计入口、靠近、侧绕、遮挡和退远 | 固定地标、补齐背面与承托面，树木不悬空 |
| 4. 全场景美术 | 按原画生成或绘制立面、屋顶、石岸、地面、树皮、船板、透明枝叶与完整天空 | 各面语义、轮廓、色块和笔触一致；UV不拉丝 |
| 5. 内部试制 | 先做最难5秒，再检查入口、主体侧面、背侧、遮挡、解除遮挡和全景 | 真实视差与稳定身份；样片不代替用户要的完整影片 |
| 6. 全片渲染 | 固定场景版本，分配不重叠帧范围，原生规格逐帧输出 | 修改场景/材质/相机后重渲；旧缓存指纹不匹配就停止 |
| 7. 原图简介 | 核对作品、作者、年代与地点，独立文字区淡入 | 完整原图、无缺字、不遮主体，约6–10秒阅读 |
| 8. 合成验收 | 原创或已获准音乐，临时MP4编码成功后原子替换 | 规格、音画时长、完整解码和目视画面全部通过 |
| 9. 交付 | MP4、可编辑场景与后期、实际材质、提示词、验收记录 | 原生与插值/放大如实标注，来源与空间补全说明清楚 |

## 当前已验证方案

《罗讷河上的星夜》个案：新绘画材质 → Three.js/WebGL真实三维场景 → 原生1080p/30fps、22秒/660帧 → Remotion原图与简介8秒/240帧 → FFmpeg合成30秒/900帧。完整解码、源帧完整性、音画时长和关键视角检查已通过。

模板和技能中的素材生成步骤可复用。其他画作需要重建自己的场景，不能直接得到同一个河岸、船与城市；画作身份未核实时不编造作者简介。已覆盖地标和技术验收，不等于与参考逐像素相同。

## 本次固化的故障处理

- **水面空底但视频能播放**：检测浏览器Shader错误，修复GLSL浮点常量与统一世界坐标相位，重新渲染。
- **树木悬空**：补出实体岸坡和树根承托，再检查新的视角。
- **修改场景却复用旧JPEG**：帧目录绑定代码、材质、依赖锁和规格指纹；不匹配立即停止。
- **文件缺少moov**：编码到临时文件，结束后原子替换，再完整解码。
- **作者或画名混淆**：按实际原图查证，不能将1889年《星月夜》背景套到1888年《罗讷河上的星夜》。

```text
用 $paint-world-flythrough 把我上传的画制作成完整30秒穿行视频。
原生1080p、30fps；前22秒进入画中空间，靠近主体、绕到侧面、经过前景遮挡，再升高拉远。
细化所有镜头可见的地标与绘画材质，根部和背面补齐。
最后8秒完整展示原图，加入核实后的作者、作品年代和创作背景简介。
不使用付费图生视频服务；缺少可逆本地依赖自行准备。
先内部验证最难镜头，随后完成全片，交付MP4、可编辑工程与验收记录。
```
